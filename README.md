# Natali Design — Portfólio

Portfólio pessoal de Natali, Product Designer UX/UI.

Design próprio, criado no Figma e implementado em código.

## Tecnologias

- [Next.js 16](https://nextjs.org) (App Router)
- [React 19](https://react.dev)
- [Tailwind CSS 4](https://tailwindcss.com)
- JavaScript

## Funcionalidades

- Bilíngue (português e inglês), com o idioma salvo entre visitas
- Tema claro e escuro, respeitando a preferência do sistema
- Carrossel vertical de projetos, com modal para cada um
- Layout fiel ao design do Figma (canvas 1920×1024), que escala junto com a janela
- Sem rolagem: cada seção cabe inteira na tela
- Ponteiro e sons de clique personalizados

## Rodando localmente

Instale as dependências:

```bash
npm install
```

Suba o servidor de desenvolvimento:

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Outros comandos

```bash
npm run build
```

Gera a versão de produção.

```bash
npm run lint
```

Verifica o código em busca de problemas.
